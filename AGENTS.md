# Next.RS

- Use [docs/GUIDE.md](docs/GUIDE.md) for framework routing, rendering, and build commands.
- For interface work, start with the [Forge UI guide](docs/FORGE_UI.md). The optional `@nextrs/ui` package lives in `packages/forge-ui`. Import React components from `@nextrs/ui` and its stylesheet once from `@nextrs/ui/styles.css`.
- Use [Relay](examples/ui-showcase) for a working layout, theme, forms, notifications, and keyboard interactions. When changing a public component, check its types and the showcase under the server, static, and single-HTML targets.
